# next-lab

Personal playground for learning Next.js (App Router) + TypeScript.
Nothing here is stable, polished, or meant for reuse.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Experiments

- [x] App Router basics (layouts, nested routes)
- [x] Client components + hooks practice (`components/`, `hooks/`)
- [x] Server components rendering static data (`app/notes`)
- [ ] Server actions
- [ ] Streaming + Suspense
- [ ] Tailwind setup
- [ ] next/image + remote patterns
